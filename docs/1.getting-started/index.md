# 世の中の仕掛けを図に表現しよう

## `Shikake` は UMLの スペックダウン文法

`Shikake` は、普段目には見えない社会のソフトウェアを目に見えるようにすることを目指します。
[UML](https://ja.wikipedia.org/wiki/%E7%B5%B1%E4%B8%80%E3%83%A2%E3%83%87%E3%83%AA%E3%83%B3%E3%82%B0%E8%A8%80%E8%AA%9E)
や
[SysML](https://ja.wikipedia.org/wiki/Systems_Modeling_Language)
といったオブジェクト指向モデリングの流れを汲みます。
これらの記述言語は、文法が多く、それを覚えるのが大変なため、厳密に記述するのは向いているかもしれませんが、即戦的ではありません。

筆者が目指したことは、ちょうど、 HTML に対する Markdown のような存在です。
複雑に絡むソフトウェアの構造をカジュアルに記述でき、俯瞰的に「しかけ」の共有できるようにすること目指します。

## `Shikake` で行う分析プロセス

`Shikake` では、大きく３つのプロセスでソフトウェアのの構造を可視化していきます。

%fa-solid fa-hand-holding% ユースケース分析
: xxxxx

%fa-solid fa-cubes% 静的構造分析
: xxxxxx

%fa-solid fa-person-running% 動的構造分析
: yyyyyy
