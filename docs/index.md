# Shikake: Model Oriented Analysis (MOA)

情報システムを取り巻く環境は非常に複雑です。

* どのような人がどのように使おうとしているか
* 何をするときに、どんな情報にアクセスするのか
* 何をしたときに、どんな情報が生成されるのか

このように複雑であるにもかかわらず、情報システムは目に見えません。
しかも、作る人、使う人、運用する人、多くの人がかかわって使われています。
このような特徴があるので、情報システムの維持開発は、ほかの工業製品に比べて難易度が高いとされています。

また、情報産業は産業として成立しだしたのが高々数十年であるため、土木建築や金属加工などほかの産業に比べ、
歴史が浅いためまだまだ発展途上です。

そこで、筆者は、情報システムについて以下のようなものを [可視化]{.blue-text} する方法を提案します。

* そのシステムはどのように使われるのか
* システムはどのような構造をしているのか
* システムはどう動作するのか

この手法のことを  [しかけ]{.blue-text-emphasis} と名付けました。
モデルに着目して、分析することから、*Model Oriented Analysis*: [MOA]{.blue-text-emphasis} とも呼びます。

このドキュメントの目的は、[MOA]{.blue-text-emphasis} の考え方と記述方法を紹介することです。
