# Fontawesomeのテスト

## 通常の家マーク

%fa-solid fa-house%

## スタイル付き家マーク

%fa-solid fa-home%(.red-text)

## リストヘッダ

* %fa-solid fa-house% test1
* %fa-solid fa-house% test2
* %fa-solid fa-house%(.green-text) test3

## 積み上げフォント

@@ %fa-solid fa-ban fa-stack-2x%(.red-text) %fa-solid fa-camera fa-stack-1x%(.blue-text) @@
